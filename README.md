# Class Diagram Starter

A starter repo for our Class Composition Diagram work. You will begin with a simple class that has no has a relationship yet.

## How to get this repo

On GitHub, click **Use this template**, then create your team copy. You can also clone it:

```
git clone https://github.com/SH-Computer-Science/class-diagram-starter.git
```

Open the folder in your IDE after that.

## Three day plan

**Day 1.** Diagram Sneaker together on paper. Use the blank class diagram handout. Look at the fields and methods already started in `Sneaker.java`.

**Day 2.** In your team, diagram VideoGame by hand. The file `VideoGame.java` has TODO comments that list what the class should include.

**Day 3.** Code from your diagram. Fill in the TODO stubs in `Sneaker.java`, then write `VideoGame.java` from the diagram you drew. Use `Main.java` to test as you go.

## Static fields in a diagram

A static field or static method is underlined in a class diagram. You can also place static members in their own static section of the box, separate from instance fields and ordinary methods.

## Files

* `Sneaker.java`: starter with fields, a constructor, and TODO stubs that compile
* `VideoGame.java`: a class shell with TODO comments only
* `Main.java`: a simple tester for Sneaker, plus a commented section for VideoGame tests
